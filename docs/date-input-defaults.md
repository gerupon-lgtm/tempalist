# v0.8.0 日付入力の当日表示

2026-10-16の利用者依頼。対象はF-006（リスト作成）、F-012（期限）、F-013（通知設定）、管理項目の消費期限。

期限の薄い入力例が2026/09/10に固定されていたため、端末の当日に変更する。消費期限の入力例も当日にそろえる。保存・APIは従来どおりUTC、画面の日付は端末のタイムゾーン（取得不可時はAsia/Tokyo）で求める。

- 最初は実際の入力値を空に保ち、日付を指定せず保存する場合は期限なしとする。
- 空欄からカレンダーを開くと、その時点の当日を画面上の入力候補とカレンダーに入れる。日付を選ぶ操作を始めた後も、ダイアログを保存するまでは保存済みの期限を変更しない。ダイアログを取り消した場合は保存しない。
- 日付をまたいで開いた場合も、その時点の当日を使う。入力欄へ移った時とカレンダーを開いた時に入力例を更新する。
- 保存済みの日付、手入力済みの日付、入力途中・不正な日付は、カレンダーを開くだけでは上書きしない。時刻省略時の09:00も維持する。
- 新規リスト、既存リストの期限編集、通知設定、管理項目の追加・編集で共通部品を使う。
- アプリ・package・lock・manifest・Service Workerの版を0.8.0にそろえる。キャッシュ名はtempalist-shell-0.8.0となり、既存の再取得・版照合・利用者による更新操作を維持する。保存形式・通知APIの変更はない。
