# 初回サンプルテンプレート — !=テンパリスト

- 英語表記: NOT EQUAL TEMPALIST
- 状態: 発案者承認済み（2026-09-09）
- 対応: 要件定義書v1.10 F-023、実装タスクT-04
- 構成: 5種・計37項目。以下の順序・項目名を初期値として投入する

初回起動時に有効なテンプレートとして投入し、利用者が項目・メモ・並び順を編集できるようにする。通常の再起動では再投入しない。テンプレートから生成するチェックリストのチェック状態は未チェックで始める。

工場・研究向けは、現場の正式な手順書・点検表を補う個人用の確認リストとする。設備固有の点検方法・判定基準は利用者が項目・メモに追記する。アプリでの完了確定は、現場の作業開始許可や承認の代わりにはならない。

## 1. おでかけ（7項目）

1. 日時・行き先・移動経路を確認した
2. 天気を確認し、服装・雨具を準備した
3. 財布・鍵・必要な身分証を入れた
4. スマートフォンを充電し、充電器を入れた
5. 予約情報・チケットを確認した
6. 今回だけ必要な持ち物を入れた
7. 火元・戸締まりを確認した

## 2. 納品前（7項目）

1. 納品物を依頼内容・仕様と照合した
2. ファイル名・版数・形式を確認した
3. ファイルが開くこと、必要な動作を確認した
4. 誤字・記載漏れ・仮データを確認した
5. 不要な個人情報・内部メモが含まれていないことを確認した
6. 送付先・共有権限・納品期限を確認した
7. 納品物の控えと送付文面を用意した

## 3. 顧客訪問（7項目）

1. 訪問日時・場所・担当者を確認した
2. 移動経路と出発時刻を確認した
3. 訪問目的・議題・確認したいことを整理した
4. 前回の宿題・対応状況を確認した
5. 資料・名刺・必要な機材を準備した
6. 資料の内容と持ち出し範囲を確認した
7. 入館方法・当日の連絡先を確認した

## 4. 工場の始業前点検（8項目）

1. 当日の作業内容・引継ぎ事項を確認した
2. 対象設備の手順書・始業前点検表を確認した
3. 指定された作業着・保護具の状態と着用を確認した
4. 作業場所・通路・避難経路に障害物がないことを確認した
5. 設備固有の点検を、指定された安全な状態・方法で実施した
6. 安全カバー・安全装置を、指定の点検方法で確認した
7. 必要な材料・工具と、その状態を確認した
8. 点検結果を確認し、異常がある場合は作業を開始せず責任者へ報告した

機械ごとの安全事項、保護装置、作業開始前点検を確認する構成。参考: [厚生労働省「プレス機械、研削盤等を使用する作業」](https://kanairodo.mhlw.go.jp/worker/harmful/press.html)。個別機種向けの操作条件はこのサンプルに転用しない。

## 5. 研究室の実験前チェック（8項目）

1. 実験計画・手順書と、必要な承認・教育の完了を確認した
2. 使用する試料・試薬の名称、表示、使用条件を確認した
3. SDS（安全データシート）や手順書で、危険性・禁止事項を確認した
4. 作業に適した保護具を準備・着用した
5. 装置・器具の状態と、必要な換気設備の作動を確認した
6. 試料ラベル・実験記録・データ保存先を準備した
7. 廃液・廃棄物の分別方法と、適合する回収容器を確認した
8. 緊急時の停止方法・連絡先・対応設備を確認し、不明点を担当者と解消した

化学物質を扱う実験を想定し、危険性の事前確認、保護具、廃棄準備を含める。参考: [宮崎大学 工学部「安全衛生ガイドブック（令和7年4月）」](https://www.miyazaki-u.ac.jp/tech/mediadata/pdf/anzen_R07.pdf)。実験の種類に応じて現場の手順書で補う。
