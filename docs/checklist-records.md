# チェックリストの記録とメール（v0.3.0）

## 備考の入力

チェックリストの項目の下に「リスト全体の備考」を常時表示する。画面から直接編集し、「備考を保存」で保存する。完了前も完了後も入力できる。完了確定・メール用の書き出しでも、そのリストの未保存の備考を先に保存する。保存できない場合は確定・出力へ進まない。

未保存の入力はアプリ内の画面切り替えやチェック操作による再描画でも保持する。未保存の入力があるときの再読み込み・ページ終了ではブラウザの確認を要求する（ブラウザやOSによって確認が出ない場合もあるため、記入後は保存する）。別タブで同じ備考が更新されていた場合は上書きせず、入力を残して競合を知らせる。その場合は未保存の文章をコピーしてから再読み込みし、必要な内容を追記して保存する。

完了後に備考を変えても `settledAt`・チェック状態・項目順は変えない。備考の更新日時は別に保存する。再開時には既存仕様どおり完了日時を消し、次の確定で新しい日時になる。過去の出力ファイルは影響を受けない。備考はテンプレートへの書き戻し対象外。

## メールで持ち出す

1. チェックリストを開き、「メール・記録を書き出す」を押す。未完了でも利用できる。
2. 件名（チェックリスト名）と本文（状態・日時・全体備考・項目順・チェック状態・各コメント）を確認する。
3. ファイル共有に対応する端末では「メールアプリへ共有（JSON付き）」からメールアプリを選ぶ。送信先の指定・送信はメールアプリで行う。共有処理の成功はメール送信完了を意味しない。
4. 共有先が件名・本文・添付を受け取らない場合は「JSONを保存」と「件名をコピー」「本文をコピー」を利用する。「共有できない場合・PCで送る場合」の「メールを開く」はJSONを自動添付しない。保存したJSONを自分で添付する。本文が長い場合は貼り付ける。
5. PC用には「JSON添付済みメール（.eml）を保存」も利用できる。UTF-8の件名・本文とJSON添付を含むMIMEファイル。メールソフトによって、下書きとして開く・新しいメッセージとして編集する等の操作が異なる。対応しないソフトでは4の方法を利用する。

メール送信用のサーバー、送信API、宛先の保存は追加しない。業務データは利用者が共有・保存を押した時に端末の共有先へ渡す。通知共通基盤へは送信しない。JSONとEMLはダイアログを開いた時点の同じスナップショットから生成する。最新の内容で出力するには閉じて開き直す。

## JSON形式とPCでの再利用

UTF-8、`schemaVersion: 1`、`kind: "checklist-record"`。`appVersion`、`exportedAt`（UTC）、`timeZone`（表示に使用したIANA ID）、`checklist` を持つ。

- `checklist`：ID、名称、全体備考 `remarks`、備考更新日時 `remarksUpdatedAt`、期限、チェック項目（ID・label・note・checked）、並び順ロック、状態、`settledAt`、作成・更新日時、元テンプレートID、通知の有効フラグ・相対オフセット。項目順は配列順。
- 完了日時・備考更新日時・期限が存在しない場合は `null`。進行中の完了日時を生成しない。日時はUTC ISO 8601で保存し、本文では端末のタイムゾーンの秒単位表示とUTCの値を併記する。
- 対象のリスト1件だけを含む。他のリスト、テンプレート本体、端末設定、deviceId、deviceSecret、購読情報、通知対応表、Outboxを含まない。
- PCでJSON対応ツールやスクリプトから読み込める。アプリの「設定 → JSONを取り込む」でも別リストとして追加可能。IDは再発行、元テンプレートへの参照は解除、通知はOFF、完了・備考の日時は保持。設定・保持期間は移行先に従うので、古い完了リストを取り込む場合は保持期間を確認する。
- 日時は端末の時計による利用者の実施記録。改ざん検知、本人認証、第三者のタイムスタンプ、更新履歴全件の保管は行わない。完了時点の内容を残したい場合は、その時点のファイルを保存する。添付されたファイルはアプリ側の保持期限が過ぎても独立して残る。

## 検証と残る実機確認

- ユニットテスト：旧データ互換、備考の完了前後の更新、完了日時維持、未完了出力、コメント・日本語・絵文字、MIMEの復号、ヘッダへの改行混入防止、JSON取り込み、資格情報の除外。
- 隔離Chrome：未保存の入力維持、確定前と出力前の保存、完了後の編集、再読み込み、別タブ競合、共有APIの模擬成功・失敗、共有非対応時の導線、実ファイルダウンロード。
- Python標準emailパーサーでも、実際にダウンロードしたEMLの日本語件名・本文・JSON添付を確認。
- 利用者のメールアプリで、件名・本文・JSONが揃っていることと送信後にPCで開けることを確認する。実宛先へのメール送信は自動テストでは行っていない。
