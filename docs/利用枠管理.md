# 利用枠管理

対象: v0.7.3 ／ 2026-10-01

## 目的と操作

同じ種類のライセンス・アカウント・設備等について、保有数と現在の割り当て先を管理する。管理タブで作成時に「補充・対応管理」「利用枠管理」を選択する。対象名と0以上の整数の保有数を入力し、枠は自動生成する。手動の項目追加は不要。複数リストを作成できる。

空き枠のチェック時に割り当て先を必須入力し、一括保存する。キャンセルは無変更。使用中のチェック解除は確認後に割り当て先を削除する。現在の状態だけを保存し、割り当て履歴や取り消し機能は持たない。合計・使用中・空きを表示する。

数量増加は空き枠を追加する。減少時は使用中の割り当てを保持して空き枠を減らす。新しい数量を超える番号の使用枠は、範囲内の空き番号に移す。枠番号は固定の部屋番号等ではない。使用中の数を下回る変更は拒否し、先に解除を案内する。名称・保有数の変更は詳細の編集から行う。削除は確認画面を経て行う。

表示は50枠ずつ。件数の任意上限は設けず、JavaScriptで安全に扱える整数まで検証する。未使用枠の配列は保存しない。

## 保存と競合

保存形式4のルートに allocationLists を追加する。各リストは id(UUID)、name、quantity、assignments、revision、createdAt、updatedAt を持つ。assignments は使用中のみの {slot, assignee} 配列。slot は1からquantityまでの一意な整数、assignee はtrimした空でない文字列。日時はUTC ISO文字列。

作成時のみ形式4へ移行し、既存形式1/2/3も読み取る。旧形式でallocationListsを含むデータと未知の形式は拒否する。形式4移行後は通常リスト、補充管理、消費期限、設定の保存でも4を維持する。リスト全体のrevisionを更新し、古い画面からの変更・解除・削除は拒否する。同じ枠を解除・再利用した後の古い操作も適用しない。

## バックアップと境界

全体バックアップに現在の割り当てを含める。取り込み時は新しいリストIDを発行して追加し、revisionは0、数量・割り当てを保持する。移行先の既存データと設定は保持する。旧形式の取り込みで利用枠管理を消さない。形式4の取り込み先はv0.7.0以降が必要。

業務データは端末内のみで保存する。利用枠管理は通常チェックリストの完了・保持期間、補充の共通対応リスト、消費期限通知、テンプレート、あとキュー連携には参加しない。通知APIに名称や割り当て先を送らない。

## 確認

tests/allocation.test.js と scripts/browser-allocation.mjs で数量・割り当て・解除・縮小・競合・バックアップ・旧形式互換・既存期限設定・オフラインを検証する。ブラウザ試験は隔離Chromeで行い、実機タッチ操作は利用者の試用で確認する。


### v0.7.1 名前の編集・表示順

使用中の枠の「名前を編集」から、現在の使用者・端末名を修正できます。使用中のチェックと件数は維持し、空欄は保存できません。キャンセルでは変更しません。別画面で割り当てが更新・解除された場合は古い編集の保存を止めます。

「表示順」で「番号順」「空きが上」「使用中が上」を切り替えられます。同じ状態の枠は番号順です。枠番号や割り当ては変更せず、表示だけを並び替えます。切り替え時は先頭ページに戻り、その後のチェック・解除では選択中の順序で表示します。表示順は画面内で保持し、アプリの再読み込みで枠番号順に戻ります。


### v0.7.2 空き数と番号の表示

詳細画面は空き数を大きく表示し、保有数・使用中の件数をその下に表示します。空きがない場合は「すべて使用中です」、保有数0では設定を案内します。管理一覧にも空き数を強調表示します。

各行の「枠1」「枠2」は「No.1」「No.2」に変更しました。使用開始・編集・解除の画面も同じ番号で案内します。表示順は「番号順」「空きが上」「使用中が上」です。


### v0.7.3 番号の名称

作成・編集画面の「番号の名称」で、番号の前に付ける名称を指定できます。初期値はNoで、No.1、No.2…と表示します。ライセンスならライセンス1、ライセンス2…、端末なら端末1、端末2…です。空欄は保存できません。既存リストで未設定の場合はNoです。名称の変更で使用者の割り当てや使用状況は変わりません。

名称を保存すると形式5になり、slotNameとして各利用枠管理リストへ保存します。全体バックアップと取り込みで保持します。形式5の読み込み先はv0.7.3以降が必要です。形式4以前のデータも読み取れます。旧アプリが追加設定を無視して上書きしないよう、番号名称を保存したリストは旧形式として扱いません。
