## 判断

- 新規フォルダで既存Gitリポジトリは存在しない。現在の専用フォルダに開発ブランチを持つGitを初期化する。
- 共有URLは `?t=` から `#t=` に変更する。フラグメントはHTTP送信されず、要件C-1「中身をサーバーに送らない」を満たすため。旧形式の配布実績はなく互換移行不要。[根拠](https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Fragment)
- 業務データは `tempalist:data` に単一JSONスナップショットで保存する。別々のキーへ順次保存すると途中失敗で整合が崩れるため。通知用3キーは別管理し、バックアップに含めない。
- 容量警告はlocalStorageのキー・値のUTF-16概算で4MiBを目安に事前案内し、実際の保存成功・QuotaExceededErrorを最終判定とする。ブラウザ全体の容量推定でlocalStorageの残量を断定しない。[根拠](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)
- 共有URLの初期上限は最終URLで8000文字。一般的な保証値ではなくアプリ側の運用値とし、超過時は承認済みの共有JSONへ切り替える。
- 通知未提供段階では通知許可を要求せず、期限強調表示を提供する。通知UIは未提供と明示し、有効であると誤認させない。
