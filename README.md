# !=テンパリスト

NOT EQUAL TEMPALIST — テンプレートから作る、1回ごとのチェックリスト。

**現行機能の一覧・操作方法・制約は [機能・操作ガイド（v0.4.4）](docs/機能・操作ガイド.md) にまとめています。**

v0.4.0では、あとキューから項目を渡す起動URLの受信に対応。内容を確認して1つのリストを作成し、同じ連携IDの再送は重複作成しません。送信側の仕様・生成コード・試験用リンクは[あとキュー連携仕様](docs/atoqueue-checklist-link.md)。Android優先で、iOSの起動先と保存領域は実機確認が必要です。

v0.4.4は個人試用向けのフロント実装です。テンプレート管理、リストの作成・チェック・完了・再開、書き戻し、共有、バックアップ、保持期間と容量整理を使えます。ヘッダにアイコンと名称、フッターに版数とコピーライトを表示します。

通知の端末登録・予約・取消・再送と、Service Workerによるオフライン起動に対応しました。iOSではホーム画面から開く案内を表示します。配色はA1改の画像を再確認して補正（白い背景、青みのあるグレー、薄いピンク、コーラル系アクセント、白文字の完了ボタン）。Noto Sans JPを採用し、取得失敗時は端末標準のゴシック系を使います。チェック領域と右端を除いたカード全体を約0.45秒長押しすると半透明カードで並べ替えできます。右端の↑↓で1段ずつ移動でき、⋯は編集・削除です。この操作方式は実画面で確認中です。GitHub Pagesで公開済みです。設定画面から通知基盤への接続確認・端末登録・同期の再試行・端末全体の通知停止ができます。各リストの「通知を設定」で24時間前／1時間前／期限ちょうどを選びます。既存リストの選択は維持されるため、期限ちょうどの通知は各リストで追加してください。

GitHubリポジトリは [gerupon-lgtm/tempalist](https://github.com/gerupon-lgtm/tempalist)。`feat/tempalist-foundation` と同期済みです。[公開画面](https://tempalist.sikumilab.com) は、このブランチへのpush時にUTCテスト・配信物検証後、自動更新されます。

チェックリストの項目下に「リスト全体の備考」を常時表示し、完了前後とも編集できます。「備考を保存」、または完了確定・書き出し時に保存します。「メール・記録を書き出す」から件名・本文・JSONを共有できます。PC用のJSON添付済み `.eml` 保存と、JSON保存＋本文コピーにも対応しています。使い方と記録の形式は [チェックリストの記録とメール](docs/checklist-records.md) を参照してください。

通常Chromeが旧版のままの場合は、[更新専用ページ](https://tempalist.sikumilab.com/update/)から更新できます。インストールと更新の手順は[pwa-update.md](docs/pwa-update.md)を参照してください。

v0.3.2では詳細タイトルの文字サイズと改行を調整し、編集ボタンの高さを固定しました。チェック項目も文字数と表示幅に合わせて文字サイズ・字間を調整します。期限の日付・時刻欄はフォーカスから50ms後に全選択し（v0.4.4であとキューと同じ方式へ変更）、再タップではカーソルを移動できます。数字入力時に `/`・`:` を自動で補います。欄内のカレンダー・時計アイコンからも選択できます。

## 起動

Node.js 22.12以上を使用します。本番用のフレームワーク・バンドラはありません。npm依存は開発用だけです。

```powershell
npm.cmd install
npm.cmd start
```

[ローカル画面](http://127.0.0.1:4173) をChromeなどで開きます。ファイルを直接開く方法には対応していません。専用サーバーはアプリのファイルだけを配信し、docsや開発ファイルを公開しません。

データは開いたOriginのlocalStorageに保存します。`localhost`と`127.0.0.1`、異なるポート、公開ドメインは別の保存先です。移行するときは設定からJSONを書き出し、移行先で取り込んでください。

## 検証

```powershell
npm.cmd test
npm.cmd run test:utc
npm.cmd run check
```

`npm start`を別ターミナルで起動した状態で、インストール済みGoogle Chromeを使う画面検証を実行できます。

```powershell
npm.cmd run test:browser
```

画面検証は隔離したブラウザ環境を使います。利用者のChromeプロファイルや保存データには触れません。スクリーンショットは`artifacts/`に保存します。実機iOS/Androidのタッチ操作、数週間の個人試用は別途必要です。

## 配信物の準備

```powershell
npm.cmd run package:site
node scripts/check-artifacts.mjs
```

`_site/`にHTML/CSS/ESM/Service Worker/アイコン/manifestとCNAMEをコピーします。GitHub ActionsがここだけをGitHub Pagesに配信します。公開ドメインは `tempalist.sikumilab.com`。このコマンドは公開しません。

`check-artifacts.mjs`は一時コピーで版数を意図的に不一致にし、検証が失敗することと、配信物の内容が現在のアプリと一致することを確かめます。確認用のサンプル画面は、サーバー起動中に `node scripts/capture-preview.mjs` で生成できます。

業務データは`tempalist:data`に単一JSONで保存し、保存失敗時に元データを保持します。共有URLは`#t=`内に内容を入れ、HTTPでサーバーに送信しません。容量警告は概算であり、実際の保存結果が優先されます。

カードの⋯メニューは外側クリック・Escapeで閉じます。短いメモはカード内に表示し、3行を超えて収まらない場合は「続きを読む」から画面下部で全文を読めます。書体の実画面比較は `node scripts/capture-font-comparison.mjs` で生成できます。

テンプレート詳細の「作成するリストの並び順ロック」で、新しいリストの初期状態を設定できます。リスト詳細の「並び順ロック」でON/OFFを切り替えます。ONでもチェック・メモ編集・項目追加／削除はでき、順番の入れ替えだけを防ぎます。既存データと空から作成するリストはOFFです。

上部のテンプレート／設定タブから「リスト」へ戻ると、直前に開いていたチェックリストを表示します。「一覧に戻る」またはヘッダのアプリ名で一覧へ戻れます。

公開設定と通知基盤側への登録依頼は [deployment.md](docs/deployment.md) を参照してください。

## 通知の利用

[公開画面](https://tempalist.sikumilab.com/)で期限付きリストを開き、「通知を設定」から通知をONにして保存します。初回はブラウザの通知を許可してください。既に過ぎた通知時刻は登録しません。ローカルOriginは通知基盤に未許可のため、実通知は公開画面で確認します。

通信できない場合もリストを保存でき、予約・取消は保留して再送します。オフラインでOFF／完了にした直後は取消がまだサーバーに届いておらず、以前の予約通知が届くことがあります。設定画面で同期状況を確認してください。

新しいアプリ版が待機している場合、設定画面に「新しいバージョンに更新」を表示します。初回のオンライン起動後はオフラインでも開けます。端末固有の通知資格情報はバックアップに含みません。実機の確認手順は [notification-verification.md](docs/notification-verification.md) を参照してください。
